COLLEGE CLUB WEBSITE - ASSIGNMENT 4.5

Files:
- index.html: Home page
- about.html: Club introduction and member table
- registration.html: Student club registration form
- contact.html: Contact information and office hours table
- style.css: Shared design for all pages
- favicon.svg: Browser tab icon

HOW TO RUN:
1. Extract the ZIP folder.
2. Open the CollegeClub folder in Visual Studio Code.
3. Double-click index.html in File Explorer to open it in a browser.
4. Use the navigation links to test all four pages.

NOTE:
Contact details and member names are examples. Replace them with real details if required.
The registration form is a front-end demo and does not save information to a database.
